# Simurgh-Linux

A sci-fi Linux desktop concept.

## Try the desktop

Open [`index.html`](index.html) in a modern browser to launch the Simurgh OS command deck. It is a standalone, dependency-free desktop UI prototype with a live clock, application launcher, draggable app windows, quick controls, and responsive layout.

The original Debian HUD prototype is also available in [`Simurgh_HUD_Debian_v25_Ultra.html`](Simurgh_HUD_Debian_v25_Ultra.html).
